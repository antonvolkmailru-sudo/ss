ENKEL GIT-GUIDE

Forstå Git

Git hjelper deg å lagre versjoner av arbeidet ditt, samarbeide med andre og få kontroll på endringer i kode.

GitKommandoerVS CodeMarkdownDokumentasjon

Hva er Git?

Git er et versjonskontrollsystem. Det betyr at Git lagrer historikken til filene dine. Du kan se hva som er endret, gå tilbake til en tidligere versjon og samarbeide uten at hverandre sine filer blir ødelagt.

Tenk på Git som lagringspunkter i et spill: Et commit er et lagringspunkt du kan gå tilbake til.

Hva er GitHub?

GitHub er en nettjeneste der Git-prosjekter kan lagres på nettet. Her kan du dele kode, samarbeide, se historikk og ha en sikker kopi av prosjektet.

Hva er Git Bash?

Git Bash er et terminalvindu på Windows. Der kan du skrive Bash- og Git-kommandoer. Det følger ofte med når man installerer Git.

Nyttige Bash-kommandoer

pwd

Viser hvilken mappe du er i akkurat nå.

ls

Viser filer og mapper i den aktuelle mappen.

cd mappenavn

Går inn i en mappe. Bruk cd .. for å gå ett nivå tilbake.

mkdir ny-mappe

Lager en ny mappe med valgt navn.

Nyttige Git-kommandoer

git init
Starter Git i den mappen du står i.
git status
Viser hvilke filer som er endret eller klare til lagring.
git add .
Legger alle endrede filer klare til neste commit.
git commit -m "beskrivelse"
Lagrer et punkt i historikken. Skriv kort hva du har gjort.
git push
Sender commits fra PC-en til GitHub.
git pull
Henter de nyeste endringene fra GitHub ned til PC-en.

Bruk av Git i VS Code

Åpne prosjektmappen i VS Code. Klikk på Source Control-ikonet i menyen til venstre. Der ser du endrede filer, kan skrive en commit-melding, trykke Commit og deretter Sync Changes eller Push.

Hva er en .md-fil?

En .md-fil er en Markdown-fil. Markdown er enkel tekst med tegn som lager overskrifter, lister og lenker. På GitHub brukes ofte README.md for å forklare et prosjekt.

Eksempel på README.md

# Mitt prosjekt

Dette er en kort beskrivelse.

## Funksjoner
- Viser informasjon
- Lagrer data
